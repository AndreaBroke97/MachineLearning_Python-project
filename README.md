# MachineLearning_Python-project
Web app Flask che integra un modello di Machine Learning per prevedere l'approvazione di un mutuo. Architettura MVT (Model-View-Template): un form raccoglie i dati dell'utente, una pipeline .joblib (preprocessing + classificazione) genera la previsione, e l'esito reindirizza a una pagina di approvazione o rifiuto. Con gestione delle eccezioni.
